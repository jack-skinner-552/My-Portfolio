# Coding Archive

This directory contains smaller projects, experiments, and earlier programming exercises created while learning new languages, libraries, APIs, automation tools, and development concepts.

These projects are preserved to document my development progression. For my more recent and substantial work, see the [main portfolio](../README.md).

## Archive Contents

| Project | Technologies | Description |
|---|---|---|
| [Currency](./Currency) | Java | Command-line currency conversion application built to practice Java fundamentals, user input, classes, and program flow. |
| [PokeAPI](./PokeAPI) | Python, REST APIs, JSON, Matplotlib | Collection of experiments using the PokeAPI to retrieve, process, filter, and visualize Pokémon data. |
| [Weather](./Weather) | Python, CSV, Data Visualization | Generates temperature data for U.S. states and visualizes the results using a choropleth map. |
| [Hello World Docker](./hello-world-docker) | Python, Flask, Docker | Simple Flask web application packaged in a Docker container to practice containerization and deployment fundamentals. |
| [RickRoll](./RickRoll) | Selenium, Browser Automation | Early browser-automation experiment using Selenium to automate browser navigation and interaction. |
| [RickRoll.py](./RickRoll.py) | Python, Selenium | Small Python browser-automation experiment created while learning Selenium. |
| [Rick.ps1](./Rick.ps1) | PowerShell | Small PowerShell automation exercise created while learning Windows scripting. |
| [ram_and_cpu.py](./ram_and_cpu.py) | Python, psutil, Matplotlib | System-monitoring experiment that collects and visualizes CPU and RAM utilization in real time. |
